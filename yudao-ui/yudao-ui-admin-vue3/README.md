# 智企云枢管理后台

智企云枢是 AIzyForge 打造的企业一体化智能管理平台。本目录为 Vue 3 管理后台源码。

## 环境要求

- Node.js 20.19+
- pnpm 8.6+
- 后端服务默认运行在 `http://localhost:48080`

## 本地启动

```bash
pnpm install
pnpm dev
```

浏览器访问终端输出的本地地址。生产构建与检查：

```bash
pnpm ts:check
pnpm build:prod
```

线上地址：[https://aixy99.site](https://aixy99.site)
